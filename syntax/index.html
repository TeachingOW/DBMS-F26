Create a table and insert rowsDefine a table first, then add one or more rows whose values match its columns and data types.CREATE TABLECreate a relation by declaring its columns, data types, keys, and integrity rules.CREATE VIEWSave a query under a reusable virtual-table name.CREATE INDEXBuild an access path that can speed up matching and sorting on selected columns.GRANTGive a database role permission to perform an action on an object.SAVEPOINTMark a point inside a transaction so later work can be undone without discarding earlier work.Transaction isolationChoose how strongly one transaction is separated from concurrent transactions.TransactionsTreat several statements as one all-or-nothing unit of work.EXPLAINAsk PostgreSQL to show the execution plan it chooses for a query.Recursive common table expressionRepeatedly apply a query to traverse hierarchical or graph-shaped data.Common table expression (WITH)Name an intermediate query so a larger statement can be read in clear stages.Window functionsCalculate rankings, running values, or group statistics while keeping each detail row.Set operatorsCombine compatible query results using union, intersection, or difference semantics.NOT EXISTSKeep an outer row only when the correlated inner query finds no matching row.EXISTSKeep an outer row when the correlated inner query finds at least one match.ALL subquery comparisonRequire a comparison to be true for every value returned by a subquery.IN subqueryKeep rows whose expression equals one of the values returned by a subquery.HAVINGFilter groups after aggregate values have been computed.GROUP BYCollapse rows into groups and compute one aggregate result per group.Aggregate functionsSummarize several rows with COUNT, SUM, AVG, MIN, or MAX.LEFT JOINKeep every row from the left table and attach matching right-table data when available.INNER JOINCombine rows from two tables when the ON condition is true.ORDER BYSort the final query result using one or more expressions.LIKE pattern matchingMatch text using SQL wildcard patterns.NULL testsTest whether a value is unknown using IS NULL or IS NOT NULL.SELECT DISTINCTRemove duplicate rows from the projected result.INSERTAdd one or more new rows to a table.UPDATEChange column values in existing rows that satisfy a condition.SELECT–FROM–WHEREChoose result columns, identify source tables, and optionally filter rows.
