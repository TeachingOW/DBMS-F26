SQL general syntax

SAVEPOINT

Mark a point inside a transaction so later work can be undone without discarding earlier work.

General pattern

BEGIN;
statement_1;
SAVEPOINT savepoint_name;
optional_statement;
ROLLBACK TO SAVEPOINT savepoint_name;
COMMIT;

How to read it

  • BEGIN starts the transaction.
  • SAVEPOINT creates a partial rollback target.
  • COMMIT makes all work not rolled back permanent.

Example using the course database

BEGIN;
UPDATE Product SET price = price * 0.90 WHERE category = 'Gadgets';
SAVEPOINT price_change;
UPDATE Product SET price = 0;
ROLLBACK TO SAVEPOINT price_change;
COMMIT;
