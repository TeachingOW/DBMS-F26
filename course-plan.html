32-meeting plan · Existing lecture library · Course resources

Course plan: 32 meetings of 100 minutes

16 weeks · 2 meetings/week · 100 minutes/meeting · 3,200 minutes = 53 hours 20 minutes. This plan maps the existing DBMS-F26 lecture library into teaching meetings. It does not require adding more lecture decks or presenting every slide.

Scheduling: These are 32 available teaching slots, not verified calendar dates. Holidays, cancellations, and separately scheduled exams must be reconciled with the institutional calendar. Each slot totals 100 minutes including review, practice, and feedback. Required quizzes fit within opening retrieval time. No new grading weights are introduced.

Coverage audit

The existing library already covers ER modeling, relational algebra, normalization, windows, recursion, stored programs, triggers, storage/indexes, join algorithms, optimization, transactions/logging/recovery, and MongoDB. SQL already has aligned labs. The additions here strengthen applied practice: complete performance experiments, two-session concurrency, restore verification, least privilege, and a transaction-safe application. Security/application operations are expanded rather than claimed absent; distributed decisions build on the MongoDB availability material.

Scope: PostgreSQL 16+ for new executable labs, Python for application work, and the existing MongoDB lab for document databases. Some source decks and hosted exercises use MySQL/MariaDB; use this supplement’s PostgreSQL scripts for these meetings. Graph databases, full ARIES implementation, distributed consensus internals, and multiple application languages remain optional extensions.

Getting ready

Shared fixture · Performance dataset · Python starter

Use existing course assignments and projects as the assessed work. Supplemental exercises provide separate practice; submit each assignment deliverable once. Homework preparation is additional to the 3,200 in-class minutes.
