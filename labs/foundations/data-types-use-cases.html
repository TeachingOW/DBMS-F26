Choosing SQL Data Types from Use Cases

Goal: choose a type by asking what operations must be correct—not by asking what the sample value happens to look like.

Part 1 · Classify the job of the field

Exact quantity

Money, tax rates, inventory quantities measured to a fixed scale.

Usually: DECIMAL(p,s) or NUMERIC(p,s).

Approximate measurement

Sensor readings, scientific values, estimates where floating-point approximation is acceptable.

Usually: REAL or DOUBLE PRECISION.

Identifier

ZIP code, phone number, SKU, student ID, or account number. Leading zeros and formatting matter; arithmetic does not.

Usually: CHAR or VARCHAR.

Time

Birthday, due date, event instant, or local appointment time.

Usually: DATE, TIME, or TIMESTAMP; consider time-zone semantics.

State

Yes/no, active/inactive, passed/failed.

Usually: BOOLEAN, unless the domain has more than two states.

Human text

Name, title, comment, or description.

Usually: VARCHAR(n) for a meaningful limit or TEXT for open-ended content.

Part 3 · Build and test

Create a table named event_registration. Decide types and useful constraints for every field, then insert three rows designed to test the boundaries of your choices.

CREATE TABLE event_registration (
    registration_id  /* choose */ PRIMARY KEY,
    student_id       /* choose */ NOT NULL,
    ticket_price     /* choose */ NOT NULL,
    registered_at    /* choose */ NOT NULL,
    needs_access     /* choose */ NOT NULL,
    notes            /* choose */
);

Boundary tests

  1. Use a student ID with leading zeros.
  2. Insert a price whose third decimal place is nonzero. Predict what the DBMS will do.
  3. Insert an invalid date or timestamp and record the error.
  4. Try a missing required value.
  5. Explain whether needs_access truly has two states or needs an “unknown/not answered” state.
Suggested core choices

student_id VARCHAR(...), ticket_price DECIMAL(8,2), registered_at TIMESTAMP, and needs_access BOOLEAN. The best length, nullability, default, and time-zone treatment depend on the stated requirements.

Exit ticket

Choose one field whose sample value looks numeric but should be stored as text. Explain the operation that proves your choice.
